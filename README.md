# Data Projects – Advanced Analysis and Visualisation

## Overview
This folder contains a collection of advanced data projects completed during my studies and personal work. Each project focuses on data cleaning, preparation, visual exploration and deeper analysis. Some include predictive elements where relevant.

The aim is to show complete, end-to-end examples of how raw data can be examined and turned into clear insights. All work can be viewed directly on GitHub without needing to run any code.

---

## What This Folder Contains
Every project is placed in its own folder and may include:

* Python files showing the full cleaning and analysis steps
* Images of the visual results
* A short summary describing the project and its findings
* The **original dataset** used for the analysis (no cleaned versions provided)

In the future, some projects may also include static Power BI visuals saved as images.

---

## How to Use This Repository
You can review everything directly on GitHub.

1. Open a project folder to explore its contents.
2. Read the **README.md** inside the folder for an overview of the dataset and results.
3. Browse the Python file to see how the data was cleaned and analysed.
4. View the images to see the final visualisations.
5. Move to other folders to explore different projects.
